# Portfolio admin setup

The portfolio now supports secure editing, permanent database saves, and image/PDF uploads using Supabase.

## 1. Create the backend

1. Create a project at Supabase.
2. Open **SQL Editor**, paste `supabase/setup.sql`, and run it. The script is safe to run again when new features such as visitor ratings are added.
3. Open **Authentication → Users → Add user** and create your private admin email/password.
4. Keep public email sign-ups disabled. The portfolio intentionally has no sign-up form.

## 2. Configure local development

Copy `.env.example` to `.env.local` and fill in the project URL and anon/publishable key from **Project Settings → API**.

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLIC_PUBLISHABLE_KEY
```

Never place the Supabase service-role key in this frontend app.

## 3. Configure the deployed site

Add the same two variables in the deployment provider's environment-variable settings, then redeploy. The anon key is designed to be public; Row Level Security protects writes.

## 4. Edit content

Open the deployed portfolio, select **Admin** at the bottom-right, and sign in. Edit buttons and section-specific **Add new** buttons then appear directly on the portfolio. Edit each card in place and save it there. Changes are stored in Supabase and appear on every device until edited again.

Uploaded images and PDFs are limited to 10 MB each. Only the signed-in admin can upload or change data; portfolio content and uploaded files are publicly viewable.

## Visitor ratings

The same SQL script creates the visitor-rating table. Visitors can submit a 1–5 star rating and optional feedback without signing in. The public UI can read rating scores for the live average, while written feedback remains private in the Supabase dashboard.

## 5. Enable Aivon's cinematic voice

Aivon's premium voice is generated by the `aivon-voice` Supabase Edge Function. The OpenAI API key must remain a server-side Supabase secret; never add it to `.env.local` or any `VITE_` variable.

```bash
supabase login
supabase link --project-ref YOUR_PROJECT_ID
supabase secrets set OPENAI_API_KEY=YOUR_OPENAI_API_KEY
supabase functions deploy aivon-voice --use-api
```

The function only accepts Aivon's approved portfolio dialogue, applies a basic per-client rate limit, and requests an original deep cinematic mechanical-commander delivery. It does not clone or imitate an existing character or performer. If the Edge Function is unavailable, the site automatically falls back to the visitor's browser speech engine.
